# 📊 Motorola Sales Dashboard

## 📌 Project Overview
The Motorola Sales Dashboard is an interactive data visualization project developed using Microsoft Power BI. It provides a comprehensive overview of sales performance, customer ratings, transactions, and mobile phone sales trends.

## 🚀 Key Features
- **Sales KPIs:** Total Sales, Transactions, Average Sales, and Total Quantity.
- **City-wise Sales Analysis:** Geographical visualization of sales distribution across cities.
- **Monthly Sales Trends:** Analyze product quantities by month and day.
- **Mobile Model Performance:** Compare sales across different mobile models.
- **Payment Method Analysis:** Visualize transactions by Debit Card, Cash, UPI, and Credit Card.
- **Customer Ratings:** Analyze customer feedback and rating distribution.
- **Daily Sales Analysis:** Identify sales patterns across different days of the week.
- **Interactive Filters:** Filter dashboard data by month.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Data Visualization
- Business Intelligence (BI)
- Data Analytics
- Interactive Charts and KPI Cards

## 🎯 Project Objectives
- Monitor overall sales performance.
- Identify top-performing mobile models.
- Understand customer ratings and payment preferences.
- Analyze geographical and time-based sales trends.
- Support data-driven business decisions.
